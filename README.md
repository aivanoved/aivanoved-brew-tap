# Aivanoved Aivanoved-brew-tap

## How do I install these formulae?

`brew install aivanoved/aivanoved-brew-tap/<formula>`

Or `brew tap aivanoved/aivanoved-brew-tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aivanoved/aivanoved-brew-tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
